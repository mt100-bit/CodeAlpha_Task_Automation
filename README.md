# Email Extractor 

## About the Project

A Python Email Extractor built as part of my CodeAlpha Python Programming Internship tasks. The program reads text from a file, extracts email addresses, displays them, and saves them to a separate text file.

## Features

* Reads text from `sample_text.txt`.
* Extracts email addresses using regular expressions.
* Displays the extracted email addresses.
* Saves the results to `extracted_emails.txt`.

## Technologies Used

* Python
* Regular Expressions (`re` module)
* File Handling

## How to Run

1. Ensure Python 3 is installed.
2. Download or clone this repository.
3. Make sure `sample_text.txt` is in the same folder as `email_extractor.py`.
4. Run the program:

   ```bash
   python email_extractor.py
   ```
